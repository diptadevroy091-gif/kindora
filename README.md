## ✨ Features

- **User Authentication:** Secure registration and login.
- **Google & GitHub OAuth:** Social account authentication.
- **Discover Events:** Browse community events.
- **Create Events:** Create and share events.
- **Upcoming Events:** Explore and search upcoming events.
- **Event Details:** View event descriptions, dates, and locations.
- **User Profile:** Manage personal profile information.
- **Newsletter Subscription:** Subscribe to community updates.
- **Global Dark Mode:** Switch between light and dark themes across all pages.
- **Responsive Design:** Supports desktop, tablet, and mobile devices.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/diptadevroy091-gif/kindora.git
```

### 2. Open the Project

```bash
cd kindora
```

### 3. Install Backend Dependencies

```bash
cd server
npm install
```

Configure the required environment variables in the server `.env` file, including MongoDB and authentication credentials.

Start the backend using the script defined in `server/package.json`.

### 4. Install Frontend Dependencies

Open another terminal:

```bash
cd client
npm install
npm run dev
```

### 5. Open the Website

Visit:

http://localhost:3000

Make sure the backend server is running for API features to work.
